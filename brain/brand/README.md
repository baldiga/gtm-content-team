# Brand assets

Put optional brand images here (for example a circular avatar PNG) and point `avatar_path` at the file from `config/brand.json`.

This package does not ship a photo. The photo chip is off by default and should be used only on selected hero pieces (a weekly recap, a flagship carousel cover, a personal-story post). The configured domain stays on every image, chip or not. Never use the chip on an image that quotes or shows someone else.
