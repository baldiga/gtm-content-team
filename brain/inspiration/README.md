# Inspiration library

Use this folder for visual style references you liked (a layout, a motion idea, a way of labeling a chart). Carousel Designer reads it before picking or building a template (rule R-08).

Style only. Never copy another creator's text, names, characters, logos or images into a post. Do not commit third-party posts or screenshots to a public repo unless you have the right to share them.

This package ships empty. Add your own notes here, for example:

- What you liked about a layout (grid, motion, typography)
- Which of your templates it should improve, or whether a new template is needed
- A saved frame in a private, non-public folder if you need a visual reminder
