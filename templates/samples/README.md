# Template samples

This folder is empty on purpose. The original working samples carried a personal name, domain and real post copy, so they are not part of this public package.

Generate your own samples after you fill in `config/brand.json`:

```bash
python3 carousel-kit/templates_kit/run_samples.py carousel-kit/templates_kit/specs/demo-week.json --run demo
```

Rendered PNG, GIF and MP4 files land here and are gitignored. Keep real-week outputs out of the public repo.
